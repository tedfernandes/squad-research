# Colaborar com o Squad

O Squad é uma empresa automatizada de serviços digitais: agentes de IA fazem o trabalho, com supervisão humana. Dá para colaborar de duas formas.

## 1. Com o projeto original (framework)

O framework de agentes e skills é a base de tudo. Para contribuir com ele, abra uma solicitação em [Quero colaborar](https://github.com/tedfernandes/squad-research/issues/new?template=colaborar.yml) e escolha "Framework Squad".

## 2. Com as frentes da empresa

A empresa toca projetos de cliente em várias frentes. Os projetos em si são privados, então o casamento com um projeto acontece depois, em conversa. Você se candidata por frente:

- **Dev**: back-end, front-end, full-stack, QA.
- **Marketing**: copy, tráfego, design, vídeo, social.
- **Comercial**: prospecção, proposta, sucesso do cliente.
- **Diretoria**: produto, operações, financeiro, jurídico.
- **Design**: UX/UI e identidade visual.

Escolha a frente no mesmo formulário: [Quero colaborar](https://github.com/tedfernandes/squad-research/issues/new?template=colaborar.yml).

## Como funciona depois

1. Você envia a solicitação (vira uma issue aqui).
2. A gente responde pela issue ou pelo contato que você deixou.
3. Se fizer sentido, você recebe acesso só ao que for necessário.

Não inclua dados de cliente, chaves ou segredos na solicitação.
